# 주식 위젯 예제

속성 설명은 [README.md](README.md). 아래 종목과 가격은 모두 가상입니다.
태그는 **답변 맨 끝에 한 줄**로 씁니다. 속성 값 안에는 큰따옴표(`"`)를 쓸 수 없고, 값은 500자까지입니다.

## 1. 가장 짧은 태그

```
<lunatalk_asset id="stock" />
```

전부 기본값(루나전자, 71,200원)으로 그려집니다. 모양을 확인할 때 씁니다.

## 2. 종목 하나 (원화)

```
<lunatalk_asset id="stock" name="루나전자" code="LUNA" price="71200" prev="70500" seed="a1" date="2026-10-09" />
```

- 현재가 71,200원, 전일 종가 70,500원 → ▲700 (0.99%)
- 호가 단위는 100원 (71,200원 구간)
- 처음 현금은 10,000,000원

## 3. 다른 종목은 `code`와 `seed`를 바꾼다

```
<lunatalk_asset id="stock" name="달빛바이오" code="MOON" price="15300" prev="15500" seed="moon7" />
```

- `code`가 다르면 보유 종목이 따로 저장되고, **현금은 같이 씁니다.**
- `seed`가 다르면 차트 모양이 다릅니다. 같은 종목은 늘 같은 `seed`를 씁니다.
- 현재가가 전일보다 낮아서 파랑(▼)으로 표시됩니다. 호가 단위는 10원입니다.

## 4. 어두운 채팅방

```
<lunatalk_asset id="stock" name="루나전자" code="LUNA" price="71200" prev="70500" seed="a1" theme="dark" />
```

위젯 배경은 투명이 아니라 직접 칠한 색입니다. 채팅방이 어두우면 `theme="dark"`를 넣습니다.

## 5. 달러 종목

```
<lunatalk_asset id="stock" name="Aurora Systems" code="AURA" cur="USD" market="NASDAQ" price="347.86" prev="344.86" seed="g" cash="10000" />
```

- `cur`가 `원`(또는 `KRW`)이 아니면 소수 둘째 자리까지 표시하고 호가 단위는 0.01입니다.
- `cash`를 안 쓰면 외화는 10,000이 기본값입니다.
- 현금은 방 하나에 하나입니다. 원화 종목과 달러 종목을 같이 쓰면 같은 현금을 나눠 쓰니 단위를 맞춰 주세요.

## 6. 며칠에 걸쳐 이어가기

`day`를 1씩 올리고, `prev`에 어제 `price`를 넣고, `date`를 다음 거래일로 바꿉니다.

```
1일차  <lunatalk_asset id="stock" name="루나전자" code="LUNA" price="71200" prev="70500" seed="a1" day="0" date="2026-10-09" />
2일차  <lunatalk_asset id="stock" name="루나전자" code="LUNA" price="72800" prev="71200" seed="a1" day="1" date="2026-10-12" />
3일차  <lunatalk_asset id="stock" name="루나전자" code="LUNA" price="70900" prev="72800" seed="a1" day="2" date="2026-10-13" />
```

- 2026-10-09는 금요일이고 다음 날짜가 월요일(10-12)이라 **주말을 건너뜁니다.** 토·일을 적어도 마지막 캔들은 앞 평일로 맞춰집니다.
- `seed`는 고정합니다. 바꾸면 차트 모양 전체가 달라집니다.
- 과거 캔들 모양은 그대로이고, 가격 높이는 `prev`에 맞춰 조정됩니다.

## 7. 캐릭터 프롬프트에 넣는 문장 (복사해서 쓰기)

```
[주식 위젯 규칙]
- 매 답변 맨 끝에 아래 태그를 한 줄로 붙인다. 다른 말은 그 뒤에 쓰지 않는다.
- price 는 오늘 종가, prev 는 직전 답변의 price, day 는 직전 답변보다 1 크게, date 는 다음 평일로 한다.
- 가격은 이야기에 맞춰 움직인다. 호재면 오르고 악재면 내린다. 하루 변동은 ±10% 안에서 정수로 쓴다.
- name, code, seed 는 절대 바꾸지 않는다.
- 사용자가 사고 판 내역과 잔고는 아래 값을 보고 안다. 계산을 따로 하거나 고쳐 말하지 않는다.

현재 잔고와 보유: {{{PF}}}

<lunatalk_asset id="stock" name="루나전자" code="LUNA" price="…" prev="…" seed="a1" day="…" date="…" />
```

- `{{{PF}}}`는 방 저장값입니다. 사용자가 체결한 뒤 **다음 턴부터** 새 값으로 바뀝니다.
- `{{{PF}}}`의 모양은 `{"cash":9501600,"pos":{"LUNA":[7,71200]}}` 입니다. `pos`는 `종목코드: [수량, 평균단가]` 입니다.
- AI가 직접 저장값을 바꿀 수는 없습니다. 잔고 변화는 사용자가 위젯에서 체결해야 생깁니다.

## 8. 사건에 따라 가격을 움직이게 하는 문장

```
[시세 변동 규칙]
- 뉴스나 사건이 나오면 같은 답변의 price 에 바로 반영한다.
  - 큰 호재: +5~10%   작은 호재: +1~3%
  - 큰 악재: -5~10%   작은 악재: -1~3%
  - 사건이 없는 날: ±1% 안에서 조금만
- prev 는 사건과 상관없이 직전 답변의 price 를 그대로 쓴다.
```

## 9. 체결을 AI에게도 알리는 경우

주문 창의 **“체결을 AI에게도 알리기 (한 턴 요금)”** 를 켜면 체결 직후 이런 메시지가 사용자 이름으로 전송됩니다.

```
[체결] 루나전자(LUNA) 10주 매수 @71,200원 · 잔고 9,288,000원
```

캐릭터 프롬프트에 이렇게 써 두면 반응을 이어갈 수 있습니다.

```
사용자가 [체결] 로 시작하는 메시지를 보내면 방금 주식을 사고판 것이다. 한두 문장으로 자연스럽게 반응한다.
```

켜지 않으면 AI 턴을 쓰지 않습니다. 체결 자체는 위젯 안에서 끝납니다.

## 자주 틀리는 것

| 증상 | 원인 | 고치는 법 |
|---|---|---|
| 차트가 갑자기 다른 모양이 된다 | `seed`나 `name`을 바꿈 (`seed`를 안 쓰면 `name`이 시드) | 종목마다 `seed`를 정해 두고 바꾸지 않는다 |
| 전일 대비가 이상하다 | `prev`가 직전 `price`와 다름 | `prev`는 직전 답변의 `price` 그대로 |
| 지난 답변의 창이 기본값으로 보인다 | 속성 이름(`price` 등)을 나중에 바꿈 | 속성 이름은 바꾸지 않는다 |
| 지난 답변에서 주문하면 옛 가격으로 체결된다 | 창마다 그 답변의 `price`를 쓴다 | 정상 동작이다. 최신 답변에서 주문하도록 안내한다 |
| 잔고가 안 늘어난다 | 현금은 사용자가 팔아야 늘어난다 | AI가 대신 바꿀 수 없다. 위젯의 **잔고 초기화**로 되돌릴 수는 있다 |
| 태그가 글자 그대로 보인다 | 큰따옴표가 값 안에 들어갔거나 `id`가 다름 | `id`는 등록한 에셋 ID와 같게, 값에는 `"`를 쓰지 않는다 |
