# 주식 위젯 (`stock`)

모바일 증권앱 화면. 시세는 **가상**이고(외부 통신이 막혀 있다), 잔고와 보유 종목은 방 저장값에 남는다.

- 차트: 일·주·월 캔들, 이동평균(5·20), 일목균형표(9·26·52), 거래량, 현재가 표시, 터치 십자선
- 호가: 매도·매수 10단계 호가와 잔량 (가상)
- 내 주식: 현금, 보유 수량, 평균단가, 평가손익, 총 자산, 잔고 초기화
- 주문: 수량 입력(−/+/+1/+10/+100/최대) → 시장가 체결. 체결은 위젯 안에서 끝나고 **AI 턴을 쓰지 않는다**
- 크기: 약 19KB (한도 100KB)

## 호출 태그

```
<lunatalk_asset id="stock" name="루나전자" code="LUNA" price="71200" prev="70500" seed="a1" day="0" date="2026-10-09" />
```

| 속성 | 기본값 | 뜻 |
|---|---|---|
| `name` | 루나전자 | 종목명 |
| `code` | LUNA | 종목 코드. 보유 종목의 키로 쓰이니 종목마다 다르게 |
| `price` | 71200 | 현재가 |
| `prev` | price 의 99% | 전일 종가. 등락과 호가 기준 |
| `seed` | 종목명 | 같으면 같은 차트 |
| `day` | 0 | 며칠째인지. 올리면 과거 캔들은 그대로 두고 캔들이 한 개씩 늘어난다 |
| `date` | 오늘 | 마지막 캔들 날짜 (`2026-10-09`). 주말은 건너뛴다 |
| `cur` / `market` | 원 / 루나거래소 | 통화(원이면 정수, 그 외는 소수 2자리), 시장 이름 |
| `cash` | 10,000,000 (원) / 10,000 | 처음 가진 현금 |
| `theme` | light | `dark` 면 어두운 화면. 배경이 투명이라 채팅 테마에 맞춰 고른다 |
| `tick` | 자동 | 호가 단위. 원이면 한국거래소 표, 그 외는 0.01 |

## 저장값 `PF`

잔고와 보유는 방 저장값 `PF` 하나에 JSON 문자열로 들어간다. 모든 종목이 같은 현금을 나눠 쓴다.

```
{"cash":9501600,"pos":{"LUNA":[7,71200]}}      // pos: 코드 → [수량, 평균단가]
```

- 저장값 한도 2,000자 → 1,900자를 넘기면 체결을 막는다 (종목 수십 개 수준).
- 캐릭터 프롬프트에 `{{{PF}}}` 를 넣어 두면 AI 가 다음 턴부터 잔고와 보유를 안다.
- 체결 때마다 방 저장값을 다시 읽어서 계산하므로, 다른 탭에서 바뀐 값이 덮어써지지 않는다.

## AI 에게 시키는 법 (프롬프트 예)

```
답변 끝에 아래 태그를 한 줄 붙인다. price 는 오늘 종가, prev 는 어제 종가, day 는 1씩 올린다.
호재면 올리고 악재면 내린다. 하루 변동은 ±10% 안에서.
<lunatalk_asset id="stock" name="루나전자" code="LUNA" price="…" prev="…" day="…" date="…" />
현재 잔고와 보유: {{{PF}}}
```

## 알아둘 점

- 지난 답변의 태그는 그 시점의 `price` 로 그려진다. 지난 답변에서 주문해도 **그 답변의 가격**으로 체결된다.
- 속성 이름(`price`, `prev` 등)을 바꾸면 옛 답변의 창이 기본값으로 그려진다.
- 수수료·세금·호가 단위 체결은 넣지 않았다. 시장가로 전량 체결한다.
- 미리보기와 로컬 시험에서는 `LT` 가 가짜다 (`dev/preview.html`, 저장값은 localStorage). 실제 채팅방에서 확인 전이다.
